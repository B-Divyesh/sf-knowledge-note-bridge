How this site handles your data

Knowledge Note Bridge keeps your Markdown, Anki collection, backups, manifests, and sync reports on your computer.

CLI connections

The CLI calls only the AnkiConnect address you choose. It has no analytics or telemetry.

Browser sample

The demo processes sample Markdown in your browser. It never sends that Markdown to another service.

Edits use session storage keys beginning with demo:knb:. Reset clears them, and closing the tab removes them.

Licenses and payment

The home page stores a pasted Steward token under sb_license:knowledge-note-bridge. It sends the token to Sociobot for license checks.

A valid result is cached for one day. Checkout runs on Sociobot/Dodo, which handles payment details and refunds.

Remove stored data

Clear this site's browser storage to remove license data. Delete .knb/ only after keeping the recovery files you need.
