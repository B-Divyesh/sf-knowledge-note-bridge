How it works

Review every change before sync

The bridge compares stable source IDs with existing Anki notes. Unclear changes stop the sync.

  1. Add stable card IDs

    Put an ID in each Markdown card block. The ID stays the same when wording or files change.

  2. Save the dry-run plan

    Review each add, update, rename, archive, or blocked item before you approve the file.

  3. Back up and sync

    A matching approved plan makes Anki backups before the first write. The bridge then records a recovery report.

Install the CLI

Start with the safe sample

Install the Rust binary, then run the bundled sample before using your notes.

cargo install --git https://github.com/B-Divyesh/sf-knowledge-note-bridge
sampleknb demo
checkknb check notes/
planknb plan notes/ --json > plan.json
syncknb sync notes/ --yes --plan plan.json

Privacy and limits

Your notes stay under your control

This is a sync safety tool. It is not a note editor, cloud service, or automatic card writer.

  • Local connections only

    The CLI reads your files and calls the AnkiConnect address you choose. It sends no analytics.

  • Missing cards stop the sync

    A missing source card becomes a blocked item. You must restore, rename, or archive it.

  • Archives do not delete cards

    An archive adds a tag and suspends existing cards. The backup and report support recovery.
